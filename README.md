# 삼국지 카드 배틀 (가제)

## 컨셉
- 장르: 확률형 카드 수집 + 배틀
- 소재: 삼국지 장수
- 그래픽: 웹 기반 (2D 수준)
- 플레이 방식: 원격 접속, 멀티플레이어(여러 명이 함께 접속하여 진행)

## 실행 방법

### 1. 나 혼자 테스트
PowerShell에서:
```powershell
cd backend
.\run_server.ps1
```
브라우저에서 `http://localhost:8123` 접속.

(최초 1회, 파이썬 패키지 설치가 안 되어 있다면: `cd backend; python -m venv .venv; .venv\Scripts\python.exe -m pip install -r requirements.txt`)

### 2. 같은 공유기(같은 와이파이) 친구랑 같이 하기
1. 위와 같이 `run_server.ps1`로 서버를 켠 채로 둡니다.
2. 내 PC의 로컬 IP를 확인합니다: PowerShell에서 `ipconfig` 실행 → "IPv4 주소" 값 확인 (보통 `192.168.x.x` 형태).
3. 친구는 같은 와이파이에 연결한 상태에서 브라우저로 `http://<내 IP>:8123` 접속.
4. 안 열리면 Windows 방화벽에서 파이썬(python.exe)의 사설망(개인) 네트워크 인바운드를 허용해줘야 할 수 있습니다.

> 참고: 이 PC에서 확인한 IPv4 주소는 일반적인 사설 IP(`192.168.x.x`) 형태가 아니었습니다.
> 네트워크 구성에 따라 `ipconfig` 결과가 다를 수 있으니, 실제 접속 전에 같은 와이파이의 다른 기기에서
> 먼저 접속해봐서 확인하는 걸 권장합니다. 만약 그 IP가 공용 인터넷에서도 그대로 노출되는 주소라면
> (예: 회사/기숙사 네트워크) 낯선 사람도 접근할 수 있으니 주의가 필요합니다.

### 3. 나중에 원격 서버(클라우드)로 옮기기
지금 구조 그대로 서버만 클라우드에 올리면 됩니다 (기획 문서 5번 항목 참고).
