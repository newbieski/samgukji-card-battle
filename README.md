# 삼국지 카드 배틀 (가제)

## 컨셉
- 장르: 확률형 카드 수집 + 배틀
- 소재: 삼국지 장수 125명 x S/A/B/C/D/E 6등급 = 750장
- 그래픽: 웹 기반 도트(픽셀) 스타일. 초상화와 전투 배경은 AWS Bedrock으로 생성
- 플레이 방식: 비로그인(닉네임만), 방 코드로 초대하는 멀티플레이

## 플레이 모드

| 모드 | 내용 |
|------|------|
| **시나리오** | 역사적 전투 12곳 x Lv1~Lv5 = 60 스테이지. 전투 안에서 Lv1을 깨야 다음 레벨이 열린다. 내 덱 또는 그 전투의 고정덱으로 도전하며, 고정덱은 안전한 대신 보상이 60%다. |
| **싱글 플레이** | AI 상대와 무작위 덱으로 연습 대결 |
| **멀티플레이** | 방 코드로 친구를 초대해 1:1 |

전투는 5장씩 양 덱을 펼쳐놓고 진영이 번갈아 행동하는 라운드제다. 매 차례
**행동할 장수 / 스킬 사용 여부 / 대상**을 직접 고르거나 AI에게 맡길 수 있고
(전투 중에도 토글 가능), 12라운드 안에 승부가 안 나면 **일기토**로 결판을 낸다.

## 실행 방법

### 1. 나 혼자 테스트
PowerShell에서:
```powershell
cd backend
.\run_server.ps1
```
브라우저에서 `http://localhost:8123` 접속.

(최초 1회, 파이썬 패키지 설치가 안 되어 있다면: `cd backend; python -m venv .venv; .venv\Scripts\python.exe -m pip install -r requirements.txt`)

### 2. 같은 공유기(같은 와이파이) 친구랑 같이 하기
1. 위와 같이 `run_server.ps1`로 서버를 켠 채로 둡니다.
2. 내 PC의 로컬 IP를 확인합니다: PowerShell에서 `ipconfig` 실행 → "IPv4 주소" 값 확인 (보통 `192.168.x.x` 형태).
3. 친구는 같은 와이파이에 연결한 상태에서 브라우저로 `http://<내 IP>:8123` 접속.
4. 안 열리면 Windows 방화벽에서 파이썬(python.exe)의 사설망(개인) 네트워크 인바운드를 허용해줘야 할 수 있습니다.

> 참고: 이 PC에서 확인한 IPv4 주소는 일반적인 사설 IP(`192.168.x.x`) 형태가 아니었습니다.
> 네트워크 구성에 따라 `ipconfig` 결과가 다를 수 있으니, 실제 접속 전에 같은 와이파이의 다른 기기에서
> 먼저 접속해봐서 확인하는 걸 권장합니다. 만약 그 IP가 공용 인터넷에서도 그대로 노출되는 주소라면
> (예: 회사/기숙사 네트워크) 낯선 사람도 접근할 수 있으니 주의가 필요합니다.

### 3. 나중에 원격 서버(클라우드)로 옮기기
지금 구조 그대로 서버만 클라우드에 올리면 됩니다 (기획 문서 5번 항목 참고).

## 개발용 스크립트 (`backend/dev_scripts/`)

| 스크립트 | 용도 |
|----------|------|
| `illustration_agent.py` | Bedrock(Nova Canvas)으로 장수 초상화·배경 생성 |
| `generate_battle_scenes.py` | 전투 배경 12장 생성 |
| `calibrate_scenario.py` | **시나리오 60스테이지 난이도 캘리브레이션.** 장수 스탯이나 전투 공식을 바꾸면 반드시 다시 돌려야 한다 |

난이도는 손으로 맞출 수 없다. 등급을 똑같이 맞춰도 장수의 스탯·스킬 궁합 때문에
고정덱 승률이 전투마다 0%~100%로 튀기 때문에, `calibrate_scenario.py`가 실제 전투
엔진을 수만 판 돌려 목표 승률(Lv1 85% → Lv5 55%)에 맞는 적 보정값을 뽑는다.
